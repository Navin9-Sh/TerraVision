About

Land-use and land-cover classification using deep learning and Sentinel-2 satellite imagery.

What is this project?

TerraVision classifies satellite images into 10 land-use and land-cover categories using a ResNet50 model trained on the EuroSAT dataset -- 27,000 Sentinel-2 satellite images from across Europe. This version is a full rebuild of an earlier Flask prototype into a production-shaped stack: Spring Boot for the API, PostgreSQL for prediction history and user accounts, and Deep Java Library for running the trained model natively inside the JVM.

What is EuroSAT?

EuroSAT is a benchmark dataset based on Sentinel-2 satellite imagery covering 10 land-use classes. Each image is a 64x64 pixel patch captured at 10-meter resolution. The dataset contains 27,000 labeled images used to train the classification model.

How does the model work?

ResNet50 -- a 50-layer deep convolutional neural network pretrained on ImageNet -- was fine-tuned in two phases: first training only the final layers, then the entire network. This achieved 97.85% test accuracy on the EuroSAT dataset. See the Model Info page for the full architecture, dataset, and limitations writeup.

Why Spring Boot + DJL instead of Python?

The goal of this rebuild was an end-to-end JVM-native system: Java handles the HTTP API, persistence, authentication, and -- via Deep Java Library's PyTorch engine -- the model inference itself, loading a TorchScript export of the trained model directly into the JVM process. Python's only role is a one-time, offline export script; it never runs as part of the live application. The full reasoning is in ARCHITECTURE.md in the project repository.
